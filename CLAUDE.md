# Working on this repo

- Keep `CHANGELOG.md` up to date: every change that users would notice gets a line under **Unreleased** (Added /
  Changed / Fixed / Removed) in the same commit or merge, in plain words, with the commit hashes when known. If a
  commit or merge lands with a title that doesn't say what it is, add it to the changelog's "Notes on the history"
  table instead of rewriting pushed history.
