# Keyboard shortcuts

[← Back to the README](../README.md)

These are the main keys while hosting. For all of them, press `?` or **❔ Help** at the end of the host panel's bar,
before or during the game. That window starts with the keys for the screen you're on, has a filter, and can show the
editor's keys too. After an update it also lists **🆕 What moved in this version**, and the filter finds a renamed
button by its old name.

See [Hosting a game](hosting.md) for how the show runs.

## Running the show

| Key | Action |
|---|---|
| `Ctrl+Enter` (pre-game screen) | Start the game |
| `N` | The blue button: the show's next step |
| `Shift+N` | One step back |
| `Shift`+click on the blue button | Go on without the check |
| `R` | Reveal or hide the answer |
| Arrow keys on the board | Move between tiles; `Enter` opens one |
| `Esc` | Back to the board at once (the tile is used up) |
| `Shift+Esc` | ↩ Put back (keep tile): the tile stays playable |
| `K` or `B` | "Be right back" cover |
| `Ctrl+Z` / `Ctrl+Shift+Z` or `Ctrl+Y` | Undo / redo |
| `L` | Log: the history, scores and rolls |

## Players and scores

| Key | Action |
|---|---|
| `1`–`9` | Select player 1–9 |
| `0` | Select everyone or no one |
| `P` then `1`–`9` | Make that player the picker |
| `Enter` / `Shift+Enter` | Award / deduct |
| `C` / `X` | Final reveal: right / wrong |

## Tools and timers

| Key | Action |
|---|---|
| `T` / `Shift+T` | Start or pause the timer / 10 more seconds |
| `D` | Roll the dice again |
| `W` | Wheel (on a partner clue: spin for a partner) |
| `O` | Roll-off (on a tie for first, or a buzzer tie) |
| `S` | Scoreboard |

## Phone buzzers

| Key | Action |
|---|---|
| `U` | Open the buzzers (when they open on your key) |
| `0` | During a clue: reset the buzzers |

## Windows and media

| Key | Action |
|---|---|
| `A` | Open or bring forward the audience window |
| `Shift+A` | Open the scores-only window |
| `H` | Hide or show the host controls |
| `F` | Full screen |
| `Space` / `←` `→` / `M` | Play or pause, seek, mute media |
| `Shift+M` | Stop the game's sounds on stream |
| `Y` | Open YouTube or online media in its own window |
| `?` | Every key, with a filter |

## RPG and board-game rounds

| Key | Action |
|---|---|
| Arrows, numpad or `Alt`+arrows (RPG) | Move the party |
| `J` (RPG) | Full map |
| `V` (RPG) | Map on screen |
| `G` (RPG) | Regroup everyone here |
| `I` (RPG, board game) | Player sheet |
| `D`, then `Enter` (board game) | Roll, then move |
| `E` (board game) | ✎ Edit board while you play |

## Menus

Right-click, `Shift+F10` or the menu key opens the menu of what you point at, or what has the keys: a player, a tile, a
board-game space, or the stage. Each item shows its key.

## In the check

When the blue button finds something left to do, it opens a small card (the check):

| Key | Action |
|---|---|
| `Enter` | The fix marked ⏎ |
| `Shift+Enter` | The fix marked ⇧⏎ |
| `N` | Go on anyway (except into an answer: use `R`) |
| `Esc` | Not yet |
| `W` `D` `U` `O` `C` `X` `T` | The fix that shows that key |

`1`–`9`, `Space` and the media keys work as usual with the check open. `?`, `L`, `A`, `H` and `Ctrl+Z` close it first.

## Good to know

- A key held down counts once; only the arrows repeat.
- On a partner clue, `N` never spins, sends cards or judges.
- In a Daily Double's Wager box, `Enter` is **Show question ▶**.
- On a wheel or dice tile not spun yet, `Enter` reminds you to spin (`W`) or roll (`D`) first.
